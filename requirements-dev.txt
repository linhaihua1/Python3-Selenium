# ==========================================================================
#  开发/CI 质量工具依赖（**跑测试本身不需要**，只在本地检查与流水线门禁用）
#  安装：pip install -r requirements.txt -r requirements-dev.txt
# ==========================================================================
#
#  【为什么不合并进 requirements.txt】
#    requirements.txt 是"跑 UI 用例的最小集合"，Jenkins 节点与 Docker 镜像
#    只装它就能出报告。flake8 属于"写代码的人用的"，混进去会让运行环境变重，
#    也容易让新人以为少了它测试就跑不了。
#
#  【装了它之后能做什么】
#    1. 代码规范门禁
#         python -m flake8                  # 全工程检查，有输出即为不合格
#         python -m flake8 Common/basePage.py   # 只查单个文件
#    2. 元素定位规范门禁（不需要 flake8，工程内置）
#         python -m Common.locator_policy              # 打印定位清单与脆弱度分级
#         python -m Common.locator_policy --issues      # 只看有问题的条目
#         python -m Common.locator_policy --fail-over 13  # 脆弱定位超过 13 条则退出码 1
#
#  【规则配置在哪】
#    工程根目录的 .flake8（最大行宽 120、放行 E402/W503/W504、tests/ 放开 E501）。
#    规则是"工程约定"的落地，不要随手改松。
# ==========================================================================

flake8>=7.0.0
