## 一、写用例前先记住 4 条规矩

| # | 规矩 | 为什么 |
|---|---|---|
| 1 | **用例里不写 xpath、不写账号密码、不写文件路径** | 这些分别去 `elementPage.py`、`config.ini` 里取，写死了换环境就得改代码 |
| 2 | **用例方法名必须 `test_` 开头**，要固定顺序就加数字 `test_1xxx` | unittest 只收集 `test` 开头的方法，并按方法名字母序执行 |
| 3 | **页面对象只写"动作"，用例只写"断言"** | 分层：动作在 `PageObject/`，断言在 `TestSuites/` |
| 4 | **断言失败要能留下证据** | 统一用 `check_title` 这类方法，失败自动截图、记日志 |

记住一句话：**用例层管断言，页面对象管动作，基类管操作，元素表管定位。**

## 二、模板 A：串行业务流用例（最常用，照抄 testLogin）

适用场景：一组用例共用登录态、按顺序往下走（登录 → 进系统 → 操作 → 校验）。
整个类只开一次浏览器，跑完统一关闭。

把下面代码存成 `TestSuites/testXxx.py`（文件名必须 `test` 开头），然后按 `【改这里】` 注释修改：

```python
# -*- coding: utf-8 -*-
"""
用例层：XXX 业务流程测试
==========================================================================
 业务流程（按 test_N 顺序执行）：
   test_1xxx  ->  test_2xxx  ->  test_3xxx
==========================================================================
"""

import unittest

from Common.basePage import BasePage        # 基类：管浏览器生命周期
from Common.config import Config            # 配置：账号、地址等都从这里读，别硬编码
from Common.log import log1                 # 日志：别用 print
from PageObject.xxxPage import XxxPage      # 【改这里】换成你的页面对象类


class TestXxx(unittest.TestCase):           # 【改这里】类名，建议 Test + 业务名
    """XXX 业务流程的测试用例集。"""

    driver = None

    # 【改这里】断言期望值的兜底默认值（真正生效的值来自 config.ini [assert]）
    title_page1 = '页面1标题'
    title_page2 = '页面2标题'

    @classmethod
    def setUpClass(cls):
        """类级前置：读配置 -> 开浏览器 -> 建页面对象。整个类只执行一次。"""
        # ---- 1. 从配置读参数，不要硬编码 ----
        cls.username, cls.password = Config.get_account()
        # 【改这里】按需读取你这条业务需要的配置，例如：
        # cls.some_value = Config.get('testcase', 'some_key', '默认值')

        # 【改这里】断言期望值从配置取，没有就用上面的兜底默认值
        cls.title_page1 = Config.get('assert', 'title_page1', cls.title_page1)
        cls.title_page2 = Config.get('assert', 'title_page2', cls.title_page2)

        # ---- 2. 打开浏览器 ----
        cls.base = BasePage()
        cls.driver = cls.base.open_browser()

        # ---- 3. 建页面对象，所有用例共用 ----
        cls.page = XxxPage(cls.driver)        # 【改这里】换成你的页面对象

    @classmethod
    def tearDownClass(cls):
        """类级后置：关闭浏览器。"""
        cls.base.dr_quit()

    # ---------------- 统一断言（失败自动截图，新增用例直接调它）----------------
    def check_title(self, case_name, expected):
        actual = self.page.get_title()
        try:
            self.assertEqual(actual, expected)
        except AssertionError:
            log1.error('用例失败:%s，期望[%s] 实际[%s]\n' % (case_name, expected, actual))
            self.page.get_img()              # 失败瞬间截图
            raise
        log1.info('用例通过:%s\n' % case_name)

    # ====================== 用例（test_N 决定执行顺序）======================
    def test_1xxx(self):                      # 【改这里】方法名 + 数字前缀
        """用例1：做某件事。"""                 # 【改这里】写清这条用例测什么
        case_name = '做某件事'                 # 【改这里】用例中文名，给日志看
        log1.info('执行测试用例：%s' % case_name)

        self.page.some_action()               # 【改这里】调页面对象的动作方法
        self.page.my_sleep(2)                 # 需要等页面渲染时，睡几秒

        self.check_title(case_name, self.title_page1)   # 【改这里】断言

    def test_2xxx(self):
        """用例2：再做一件事（依赖用例1的状态）。"""
        case_name = '再做一件事'
        log1.info('执行测试用例：%s' % case_name)

        self.page.another_action()
        self.check_title(case_name, self.title_page2)
```

### 模板 A 各部分要改的地方汇总

| 位置 | 改什么 |
|---|---|
| `from PageObject.xxxPage import XxxPage` | 换成你自己的页面对象 |
| `class TestXxx` | 类名 |
| `title_page1 / title_page2` | 你要校验的页面标题（兜底默认值） |
| `cls.page = XxxPage(cls.driver)` | 实例化你的页面对象 |
| `def test_1xxx` 方法体 | 你的业务步骤 + 断言 |

## 三、模板 B：独立用例（不依赖登录态，单独可跑）

适用场景：这条用例**不依赖**前面用例的状态，可以单独跑、可以并行。每条用例自己开/关浏览器。

```python
# -*- coding: utf-8 -*-
"""用例层：独立用例示例（每条用例自带浏览器，互不依赖）。"""

import unittest

from Common.basePage import BasePage
from Common.config import Config
from Common.log import log1
from PageObject.xxxPage import XxxPage      # 【改这里】


class TestXxxIndependent(unittest.TestCase):

    def setUp(self):
        """每条用例前都开一个新浏览器。"""
        self.base = BasePage()
        self.driver = self.base.open_browser()
        self.page = XxxPage(self.driver)     # 【改这里】

    def tearDown(self):
        """每条用例后都关掉浏览器。"""
        self.base.dr_quit()

    def test_xxx(self):
        """独立用例：不依赖其它用例，可单独执行。"""
        case_name = '独立用例'
        log1.info('执行测试用例：%s' % case_name)
        self.page.some_action()
        # 断言……
```

> 模板 A 和 B 怎么选？
> - 用例之间**有前后依赖**（如先登录才能上传）→ 用模板 A（共享浏览器，快且稳）。
> - 用例之间**完全独立** → 用模板 B（隔离好，单条失败不影响别的）。

## 四、页面对象方法怎么写（模板配套）

用例里调的 `self.page.xxx()`，要在 `PageObject/` 里先写好。模板：

```python
# -*- coding: utf-8 -*-
"""页面对象层：XXX 页面的操作。一个方法 = 一个业务动作，不写断言、不写 xpath 字符串。"""

from Common.basePage import BasePage
from Common.elementPage import Element1     # 【改这里】元素表


class XxxPage(BasePage):                    # 【改这里】继承 BasePage
    """XXX 页面操作。"""

    def some_action(self):
        """业务动作：点某个按钮。"""
        self.click(Element1.some_button)    # 【改这里】用元素表里的定位

    def fill_form(self, value):
        """业务动作：给输入框填值。"""
        self.type(Element1.some_input, value)
```

配套地，在 `Common/elementPage.py` 里加元素定位：

```python
class Element1:
    # ...已有元素...
    some_button = ['xpath', "//button[contains(., '按钮文字')]"]   # 【改这里】
    some_input  = ['id', 'inputId']                                # 【改这里】
```

> 页面对象里**只写动作，不写断言**；断言放回 `TestSuites/`。xpath 只出现在 `elementPage.py`。

## 五、写完怎么验证

按这个顺序，由快到慢：

```bash
# 1. 先确认用例能被收集到（不执行，最快，零风险）
python -c "import sys,os;sys.path.insert(0,os.getcwd());from Common.runner import build_suite;print('用例数 =', build_suite().countTestCases())"

# 2. 改了框架/页面对象代码，先跑单元测试守住质量门禁（不开浏览器，几十秒）
python tests/run_unit_tests.py

# 3. 最后真正跑你的用例
python run.py --cases test_1xxx,test_2xxx      # 只跑你写的这几条
# 或
python run.py --suite smoke                     # 跑冒烟子集
```

收集不到用例？99% 是这三个原因：
1. 文件名没以 `test` 开头（必须 `testXxx.py`）。
2. 方法名没以 `test` 开头。
3. `TestSuites/` 下缺 `__init__.py`（工程已自带，别删）。

## 六、常见错误对照

| 报错 / 现象 | 原因 | 解决 |
|---|---|---|
| 用例数 = 0，一条都没收集到 | 文件名/方法名不以 `test` 开头；或缺 `__init__.py` | 改名为 `test` 开头；确认 `TestSuites/__init__.py` 存在 |
| `NameError: xxx` / 找不到页面对象 | import 路径写错 | 检查 `from PageObject.xxxPage import XxxPage` 是否与文件名/类名一致 |
| 元素定位不到，报 `NoneType` | xpath 失效或页面还没加载完 | 改 `elementPage.py` 的定位；或加 `my_sleep` / 调大 `element_timeout` |
| 新开标签页后元素全找不到 | 忘了切窗口 | 调用 `switch_other_window()` |
| 用例里出现了账号/路径明文 | 违反规矩 1 | 改用 `Config.get(...)` 从配置读 |
| 单独跑某条中间用例失败 | 它依赖前面用例的登录态 | 串行用例从 `test_1` 开始跑，不能跳着跑 |
| 中文日志/报告乱码 | 编码问题 | 设环境变量 `PYTHONIOENCODING=utf-8` |

> 排查顺序：**控制台输出 → `Logs/当天/Error_Logs/` → `img/当天/` 失败截图**。

## 附：一条用例的最小骨架（速查）

```python
class TestXxx(unittest.TestCase):
    driver = None

    @classmethod
    def setUpClass(cls):
        cls.base = BasePage()
        cls.driver = cls.base.open_browser()
        cls.page = XxxPage(cls.driver)

    @classmethod
    def tearDownClass(cls):
        cls.base.dr_quit()

    def test_1demo(self):
        """用例1：示例。"""
        log1.info('执行测试用例：示例')
        self.page.some_action()
        self.check_title('示例', '期望标题')
```

照着这个骨架填肉，就是一条合格的用例。祝你写得顺利！
