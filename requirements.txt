#  运行依赖（最小集）—— 跑 UI 用例需要的
#  安装：pip install -r requirements.txt
#       或（推荐）pip install -e ".[dev]"   一次性装齐开发依赖
#
#  ★★ 为什么必须写上界 ★★
#     历史上这里只写了 selenium>=4.19.0 —— 没有上界。
#     一旦 Selenium 发布 5.x 且移除或改变了现有 API，CI 会在某天
#     **毫无征兆地全红**，而且无法复现（因为"当时装的是哪个版本"没人知道）。
#     依赖上界 + lock 文件是专为这类事故准备的。
#
#  需要逐位复现当时的环境：pip install -r requirements.lock
# ==========================================================================

# 核心依赖：浏览器自动化。Selenium 4 自带 Selenium Manager，
# 会自动下载匹配的 chromedriver，无需手动放置 driver 文件。
selenium>=4.19,<5
